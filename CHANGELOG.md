# Changelog

All notable changes to the Master Prompt Maker framework are documented here.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

---

## [v10] — 2026

### Added
- C9 domain-typed variant table — Variant A (compute/software), Variant B (practitioner/legal/clinical), Variant C (creative/editorial); mirrors C4/C6 pattern
- C1 failure-mode evidence enforceability gate — binary test: evidence must name at least one quantified threshold or observable symptom with a stated trigger condition
- C5 diversity-scaled constraint floor — minimum is now `max(4, one constraint per named solution path in C3)`; replaces flat minimum-4
- Meta-rule 19 — C9 variant must match C6 variant selected; C11 pair 1.5 confirms alignment
- Meta-rule 20 — C1 failure-mode evidence enforceability gate
- 5-step deterministic trigger stripping algorithm — eliminates multi-pass ambiguity in isolation rule
- "Forced choice not made" hard-stop row added to edge case routing table — non-generative terminal output; removes undefined three-turn stall
- C14/C15 N/A compression exemption in C12 — N/A declaration sentences excluded from compression score denominator

### Changed
- C11 expanded from 9 to 10 pairs (pair 1.5 added for C9 ↔ C6 variant alignment)
- C12 compression score formula updated: `load-bearing ÷ (total − C14/C15 N/A exempt)`

### Evaluation score: 8.7 / 10

---

## [v9] — 2025

### Added
- C3 sub-system decomposition ceiling — multi-discipline ideas require named decomposition criterion and maximum sub-system count (≤5)
- C10 failure-class diversity rule — all three next steps must address distinct failure classes, named at generation time
- C8 Never-skip enforceability floor — Never-skip items require a depth anchor (minimum/maximum sentence count or reasoning depth descriptor)
- C4 Variant B committed-value format — authority source + version/date + applicability scope for legal/compliance domains
- C6 Variant B edge case diversity gate — minimum 3 stress inputs spanning at least 2 distinct failure classes
- C6 Variant C tonal replication scoring anchor — replication test requires minimum count threshold (N ≥ 2) and a named technique property
- Meta-rules 16, 17, 18 added

### Changed
- C12 compression score threshold adjusted for C14/C15 active prompts (0.75 instead of 0.80)

### Evaluation score: 7.7 / 10

---

## [v8] — 2025

### Added
- Component 14 — Multi-turn / iterative prompt contract (OPTIONAL for single-shot tasks)
- Component 15 — Agentic chain handoff contract (OPTIONAL for standalone tasks)
- Meta-rules 14 and 15 for C14 and C15
- C11 pair 9 for C14/C15 state field grounding against C4

### Changed
- C8 3-sentence rule replaced with calibration-profile model (Known / Unknown / Skip / Never-skip fields) — flexible structure, same enforceability standard
- C6 Variant C restructured — falsifiability gate promoted to load-bearing status in C11 (pair 7)
- ACTIVATION block deduplicated — single canonical section at end of document
- C12 load-bearing classes expanded to seven (C4, C5, C2, C9, C6-Variant-C, C14, C15)

### Evaluation score: 7.3 / 10

## [v7] — 2025

### Added
- Version stamp — every generated prompt appends `[GENERATED BY: Master Prompt Maker v7]` with compression score

### Changed
- C12 load-bearing test expanded — a sentence is load-bearing if removing it loses a committed C4 value, a testable C5 constraint, a C2 success condition element, OR a C9 runtime field (previously: C4 and C5 only)

### Evaluation score: 7.0 / 10
